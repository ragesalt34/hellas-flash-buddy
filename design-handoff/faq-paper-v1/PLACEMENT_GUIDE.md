# Сборка и поведение

## Десктоп
- Контент до 1280 px; две колонки 34%/66% за вычетом зазора 64 px.
- При ширине 1440 px: поля 80 px, заголовок около 59 px, 800, интерлиньяж 1.04; блокнот до 368 px по видимой границе. В референсе блокнот уже повёрнут — CSS rotation не добавлять.
- Вопросы: 22 px/1.35, 700. Ответы: 18 px/1.6. Поля 34 px; ниже ответа минимум 28 px. Закрытый вопрос от 79 px, длинный автоматически растёт.
- Между листами 17 px. Вкладки чередуются терракотовая/синяя; высота 51 px, слева −17 px, сверху 12 px; часть уходит под лист.
- Каждый лист самостоятельный details/summary. Второй открыт в превью, в продукте начальное состояние оставить прежним.
- Никаких новых теней и свечения: контактная тень уже в PNG.

## Видимые границы и PNG
Сохранять PNG байт-в-байт, без обрезки прозрачных полей и без изменения пропорций предметов.
Изображение внутри .art смещено относительно контейнера по manifest.json. Контейнер имеет пропорции видимой границы alpha >= 16, внутренняя img абсолютная; вычисленные CSS уже в assetStyles.css.
Не использовать object-fit:cover и не подрезать ленту/печать.
Вкладки масштабировать до нужной высоты с сохранением пропорций: они не обязаны иметь одинаковую ширину.

## Бумага переменной высоты
В assetStyles.css задан CSS border-image с девятью участками и fill. Углы показаны размером 18 px, центральная пустая бумага растягивается; прозрачные поля компенсированы отрицательными inset из manifest.
Декоративный контейнер .sheet-deco на 7 px больше блока и обрезает только внешнюю прозрачную область.
Не растягивать блокнот или вкладки этим способом.
Обе бумажные подложки перекрываются, opacity меняется за 180 мс в зависимости от open.

## Мобильный вариант
До 700 px одна колонка, поля 24 px. Заголовок 36 px и миниатюра блокнота 96 px рядом.
Вопрос 18 px/1.4, ответ 16 px/1.6; поля 22 px; высота зависит от текста, без фиксированного max-height.
Не прятать длинные ответы и не обрезать строки. Декор не получает фокус, все картинки alt="".

## Анимация
Высота области ответа измеряется перед раскрытием; анимируется только область ответа, декор не обрезается. WAAPI height области ответа: 260 мс, cubic-bezier(.22,.68,0,1).
Ответ: появление 180 мс с задержкой 50 мс, сдвиг 4 px; скрытие 100 мс. Вертикальная черта + складывается за 160 мс.
Повторное нажатие меняет направление от текущей высоты; предыдущие анимации отменяются.
После завершения height и overflow снимаются: при смене языка и увеличении шрифта лист свободно растёт.
prefers-reduced-motion: без анимации. Без JS работает native details.
Фокус summary остаётся виден, нажатие Enter/Space штатное. Нет idle-анимации, свечения, тряски, автоскролла.

## Тексты
В приложении использовать существующий t('landing.faq.qN') / t('landing.faq.aN'), номера [1,4,2,6].
content.json — снимок для автономного превью, не новый источник переводов.
