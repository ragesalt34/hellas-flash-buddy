# Hellas Study — FAQ «Бумажные вкладки», v1

Выбранный вариант №2. Пять отдельных PNG с настоящей прозрачностью, сохранены в исходных размерах без сжатия, кадрирования и перекодирования. Это реконструкция элементов выбранного референса; волокна и форма надрыва могут отличаться от макета.

## Состав
- faq-notebook.png — блокнот, синяя тканевая лента, терракотовая восковая печать с храмом.
- faq-paper-collapsed.png — бумажная полоса для закрытого вопроса.
- faq-paper-expanded.png — расширенный лист для ответа.
- faq-tab-blue.png и faq-tab-terracotta.png — отдельные бумажные вкладки.

## Просмотр
Открыть preview.html в браузере или http://127.0.0.1:5173/faq-paper-preview.html при запущенном Vite.
Вопросы работают мышью и клавиатурой, RU/EL, раскрытие за 260 мс, поддерживается уменьшение движения.
Второй вопрос раскрыт только для сравнения с референсом. Превью остаётся самостоятельным стендом.

Основной FAQ подключён в LandingEditorial через LandingFaq.tsx и landingFaq.css. В приложении все вопросы изначально закрыты; тексты берутся из i18n.tsx.

## Файлы для вёрстки
manifest.json — размеры, видимые границы alpha >= 16, реальные границы alpha > 0, SHA-256, параметры nine-slice.
assetStyles.css — рассчитанная геометрия картинок и пустой бумаги.
content.json — существующие вопросы и ответы RU/EL в порядке [1, 4, 2, 6].
PLACEMENT_GUIDE.md — размеры и правила сборки.
INTEGRATION.md — границы последующей интеграции.
reference.png — выбранный пользователем макет.
prompts.json, *.prompt.txt, generated-sources.json — точные промпты и происхождение файлов. Генерация встроенным image_gen, по одному вызову на элемент.
