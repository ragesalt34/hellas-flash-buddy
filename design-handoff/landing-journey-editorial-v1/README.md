# Лента фактов и «Как это работает» — редакционный вариант

Утверждённый референс подключён в LandingEditorial.tsx, отдельные стили landingJourney.css.
Source Serif 4 600 — большой заголовок, метрики и номера. Onest 400/600 — подписи; Manrope для греческих букв.
Сохранены 160+, 150, 4, SRS и существующие ключи i18n; семь предметных иллюстраций и бумажная лента не перекодировались.
Факты располагаются равномерно в четырёх колонках на десктопе, на телефоне — в двух. До 1100 px бумажный фон уступает тонким линиям, чтобы не растягивать рваный край.
Шаги — три равные колонки, строки текста и нижние края рисунков выравниваются через CSS subgrid; предусмотрен обычный Grid fallback. До 760 px — последовательная вертикальная композиция.
Удалены цветные кружки, стрелки между шагами и вертикальные перегородки. Якорь #how-it-works сохранён.
Прежние незакоммиченные изменения других файлов сохранены.
