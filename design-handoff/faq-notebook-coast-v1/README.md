# FAQ — блокнот с бумажным побережьем

Выбранный пользователем вариант №2 из последней пары референсов.
Новый рисунок подключён вместо прежнего блокнота в LandingFaq.tsx.
Пустая бумага FAQ, вкладки, тексты и раскрытие вопросов сохранены.

- faq-notebook-coast.png — исходный PNG с прозрачностью, без сжатия, изменения размера и кадрирования.
- reference.png — выбранный макет.
- manifest.json — размеры, видимые границы alpha >= 16, расчёт положения, SHA-256 и происхождение.
- prompt.txt — полный промпт встроенного image_gen.
- Готовая копия: telegram-bot/webapp/public/assets/faq-paper-v1/faq-notebook-coast.png.

Картинка ставится по видимой границе через существующий PaperArt; пропорции не меняются. Закладка и обе вкладки целиком видны. Почти невидимые пиксели alpha 1/255 на краях исходника сохранены.
Исходный пакет faq-paper-v1 и его автономное preview.html остаются историческим вариантом с первым блокнотом.
Актуальный вариант: http://127.0.0.1:5173/#faq.

## Компоновка FAQ
На экранах шире 700 px высоту секции задаёт список вопросов. Левая колонка занимает ту же высоту: заголовок и рисунок в оставшемся пространстве, с зазором 16 px. Высота блокнота ограничена 280 px, исходное соотношение сторон сохраняется. В закрытом FAQ его нижний край совпадает со списком. На телефоне остаётся миниатюра шириной 96 px рядом с заголовком.
