# Visual polish — generated assets

Generated using the built-in image_gen tool. These 12 source PNGs are stored in art_in; game-ready copies are in assets/art, prepared with the existing tools/import_art.py pipeline. Greek text is rendered by Godot, never baked into the art. Noun gender colours and shapes, hints, hit areas, document drag-and-drop and level progression remain functional.
