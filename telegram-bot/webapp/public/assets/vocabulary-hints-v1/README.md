# Vocabulary hint assets

150 word-specific paper illustrations with transparency.
Generated with built-in imagegen. WebP files are the production assets.
Source PNGs, prompts and galleries: design-handoff/vocabulary-hints-all-150-webp-v1/ and the individual source packs in the primary clone.
The first ten retain their existing optimized 960x640 derivatives.
Use stable word IDs in src/data/vocabularyHints.ts, never shuffled session indices; preserve aspect ratio with object-fit: contain.
manifest.json records the word-to-file mapping for all 150 words.
