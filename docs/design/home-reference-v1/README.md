# Комплект Home reference v1

Подготовка отдельных изображений и элементов для одобренного референса. Экран пока не подключен.

Файлы: `telegram-bot/webapp/public/assets/pureplay/home-reference-v1/`.

| Имя PNG/WebP | Элемент | Фон |
| --- | --- | --- |
| hero | Побережье, белые дома, рука с блокнотом | Мятная и кремовая бумага |
| quiz | Спиральный блокнот и флаг | Прозрачный |
| flashcards | Карточки и оливковая ветка | Прозрачный |
| vocab | Синяя книга, рука, олива | Прозрачный |
| homework | Лист вопросов, перо, звезда | Прозрачный |
| acropolis | Акрополь для слова дня | Прозрачный |
| olive | Ветка для плана подготовки | Прозрачный |

Дополнительно: `icons/*.svg` — семь иконок lucide-react и ломаная линия прогресса по референсу; `tokens.json` — палитра, шрифты, размеры; `elements.css` — отдельные стили кнопок, ссылок, фокуса и цветных подложек, пока не подключенные к приложению; `manifest.json` — параметры изображений и контрольные суммы; `approved-reference.png` — исходный референс. PNG сохраняются как исходники, WebP используются на сайте. Предыдущие ассеты не заменяются.

## Геометрия и элементы

Референс 1448×1086. Шапка 70px; горизонтальные поля 32px; баннер 302px. Полоса четырех показателей 74px. Нижняя сетка: левая колонка 912px, правая 460px, промежуток 14px. Карточки 455×186px, зазор 12px, скругление 6px, внутренний отступ 28px. Текст слева, иллюстрация справа с обрезкой рамкой карточки. Стрелка снизу слева: круг 46px.

Слово дня: кремовый фон, Акрополь сверху, греческое слово и кнопка звука 56px рядом, перевод и тонкий разделитель ниже. План: темно-синий фон, кремовая кнопка, ветка справа. Прогресс: белая широкая карточка и линейная иконка.

Типографика: Inter 400/500/600/700/800 (уже подключен в проекте); главный заголовок 64px/800, раздел и карточки 36px, греческое слово 48px, основной текст 18px. Размеры уточняются при сопоставлении в браузере.

Тексты, кнопки, логотип, показатели, рамки и разделители создаются HTML/SVG. Цветные подложки карточек — CSS. Строки берутся из RU/EL i18n, показатели — из действующих данных. Бумажная фактура используется только в иллюстрациях. Не запекать рабочий интерфейс в PNG.

## Точность и генерация

Цвета взяты пипеткой из исходного PNG. Размеры и типографика — измеренные/оцененные отправные параметры; в растровом референсе нет исходных шрифтов или слоев. Коллажи реконструированы отдельно по референсу встроенным image_gen. Композиция и материалы сохраняются, отдельные бумажные детали могут отличаться: это не пиксельно идентичные вырезки.

Семь независимых вызовов; точные промпты сохранены в [prompts.json](prompts.json). Исходный макет подан в каждый вызов. `export-icons.mjs` воспроизводит SVG без сети.

Проверка комплекта: размеры PNG, прозрачность шести вырезок, декодирование WebP, наличие файлов, контрольные суммы, git diff --check. Реализация страницы и мобильная версия в этот этап не входят.
