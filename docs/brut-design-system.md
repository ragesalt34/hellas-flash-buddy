# Квадратная тема — дизайн-система

> Бумага, чернила и жёсткая тень. Нео-брутализм без агрессии.

**Схема:** светлая. **Характер:** плотная сетка, 2-пиксельные чернильные рамки,
смещённые тени без размытия, почти прямые углы. Каждый элемент выглядит как
плотная карточка, положенная на бумагу, а не как плоский прямоугольник в потоке.
Цвета три, и каждый занят делом: терракота — действие, лайм — успех, чернила —
всё остальное.

Документ самодостаточный: токены, рецепты компонентов и правила, которые дались
измерениями. Раздел «Запреты» читать обязательно — там ошибки, каждая из которых
уже была допущена и стоила времени.

---

## 1. Пять принципов

1. **Форму держит рамка, а не тень и не заливка.** 2px чернил по контуру —
   основа опознания элемента. Уберите рамку — рассыплется всё.
2. **Тень смещённая и без размытия.** `6px 6px 0 0 ink`. Она не «подсвечивает»
   элемент, а показывает, что он лежит выше бумаги.
3. **Углы почти прямые: 2px.** Не ноль — ноль читается как необработанный
   край. Исключение — круги (аватары, индикаторы), они остаются кругами.
4. **Цвет = смысл.** Терракота только для главного действия, лайм только для
   успеха, всё служебное — чернила на бумаге. Четвёртый цвет добавлять нельзя,
   не отняв роль у существующего.
5. **Движение физическое.** При наведении элемент сдвигается к курсору и тень
   растёт; при нажатии уходит вниз и тень сжимается. Никаких плавных
   растворений.

## 2. Цвет

| Роль | Значение | Где |
|---|---|---|
| Бумага (фон страницы) | `#f4f2ee` | подложка всего |
| Поверхность | `#ffffff` | карточки, панели, поля |
| Вторичная поверхность | `#e6e2d8` | наведение, блок ответа, пустое состояние, скелетон |
| Чернила (текст, рамки, тени) | `#111110` | текст, все рамки, все тени |
| Основной текст абзаца | `#1c1b19` | длинный текст |
| Приглушённый | `#6f6b64` | подписи, метаданные |
| Приглушённый на тонированном | `#5d594f` | текст на вторичной поверхности |
| **Терракота — действие** | `#e0523d` | главная кнопка, активный пункт меню |
| **Лайм — успех** | `#d9f21f` | верный ответ, «знаю», иконки-блоки |
| Амбер — средний шаг | `#e8a52a` | средняя оценка в шкале из трёх |
| Ошибка | `#b23a26` | неверный ответ |
| Успех-текст | `#2f8168` | там, где лайм нельзя (см. запреты) |

**Служебные:** дорожка индикатора `#e4e0d8`, скелетон `#eceae4` → `#dcd8cf`.

### Почему ошибка темнее терракоты

`#e0523d` под белым текстом 16px даёт 3.9:1 — ниже порога 4.5. Поэтому у
состояния ошибки свой, более тёмный красный `#b23a26` (5.3:1 на бумаге).
Крупные плоскости могут оставаться яркими, мелкий белый текст — нет.

### Как выведена шкала из трёх оценок

Терракота → амбер → лайм. Это не подбор на глаз: терракота стоит на тоне 9,
лайм на 67, середина тёплой дуги — 38, взято 39. Светлота тоже идёт ступенями:
0.13 → 0.44 → 0.78. Второе важнее первого — шкала, растущая по светлоте,
читается и в оттенках серого, то есть при дальтонизме.

## 3. Типографика

Один гротеск на всё, различие только в насыщенности. Ни одного второго
начертания — это часть характера.

```
Inter, system-ui, sans-serif
```

| Роль | Размер | Применение |
|---|---|---|
| hero | `clamp(40px, 9.5vw, 78px)` | только первый экран |
| h2 | `clamp(28px, 5vw, 44px)` | заголовки разделов |
| title | `clamp(22px, 3.2vw, 26px)` | заголовок карточки, результат |
| h3 | `20px` | заголовок плитки |
| числа | `clamp(30px, 5.6vw, 52px)` | крупные цифры статистики |
| лид | `clamp(16px, 2.4vw, 20px)` | абзац под заголовком |
| текст | `16px` | чтение и подписи кнопок |
| мета | `12.5px` | подписи, второстепенное |
| микро | `11px` | мелкие метки прописными |

**Веса:** 400 текст, 600 подписи, 700 заголовки, 800 акценты.
**Межбуквенное:** 0 везде, кроме микро-метки прописными — там `0.12em`.

Поле ввода **всегда 16px**, вне шкалы: iOS Safari зумит всю страницу, если у
фокусного поля текст мельче.

## 4. Размеры и формы

```
Рамка       2px, всегда цвета чернил
Радиус      2px для всего; 999px только для настоящих кругов
Тень        6px 6px 0 0 ink   (обычное состояние)
            9px 9px 0 0 ink   (наведение)
            3px 3px 0 0 ink   (нажатие)
Отступы     шаг 4px: 8 · 12 · 16 · 18 · 22 · 24 · 32 · 48
Колонка     до 720px контент, до 820px на широких экранах
```

Тень **всегда чернильная**, даже у цветных элементов. Цветные тени ломают
характер: он в том, что все предметы отбрасывают одну и ту же тень.

## 5. Готовые токены

```css
:root {
  /* Цвет */
  --bg: #f4f2ee;
  --surface: #ffffff;
  --surface-2: #e6e2d8;
  --ink: #111110;
  --text-body: #1c1b19;
  --muted: #6f6b64;
  --muted-2: #5d594f;
  --accent: #e0523d;   /* действие */
  --lime: #d9f21f;     /* успех */
  --amber: #e8a52a;    /* середина шкалы */
  --bad: #b23a26;      /* ошибка */
  --good: #2f8168;     /* успех там, где лайм не проходит по контрасту */

  /* Форма */
  --bd-w: 2px;
  --radius: 2px;
  --radius-full: 999px;

  /* Тень */
  --e1: 6px 6px 0 0 var(--ink);
  --e2: 9px 9px 0 0 var(--ink);
  --e-press: 3px 3px 0 0 var(--ink);

  /* Шрифт */
  --font: 'Inter', system-ui, sans-serif;
}

body {
  background: var(--bg);
  color: var(--ink);
  font-family: var(--font);
  font-size: 16px;
}
```

## 6. Компоненты

### Карточка

```css
.card {
  background: var(--surface);
  border: var(--bd-w) solid var(--ink);
  border-radius: var(--radius);
  box-shadow: var(--e1);
  padding: 18px;
}
```

### Кнопка — главное действие

```css
.btn {
  background: var(--accent);
  color: #fff;
  border: var(--bd-w) solid var(--ink);
  border-radius: var(--radius);
  box-shadow: var(--e1);
  padding: 15px 22px;
  font: 700 16px var(--font);
  cursor: pointer;
  transition: transform .12s, box-shadow .12s;
}
.btn:hover  { transform: translate(-2px, -2px); box-shadow: var(--e2); }
.btn:active { transform: translate(1px, 1px);   box-shadow: var(--e-press); }
```

Вторая кнопка — то же, но `background: var(--surface); color: var(--ink)`.
Третья, «успех» — `background: var(--lime); color: var(--ink)`.

### Плитка с иконкой

Квадрат иконки заливается лаймом и получает свою рамку — именно он делает
плитку узнаваемой.

```css
.tile-icon {
  width: 44px; height: 44px;
  background: var(--lime);
  color: var(--ink);
  border: var(--bd-w) solid var(--ink);
  border-radius: var(--radius);
  display: grid; place-items: center;
}
```

### Поле ввода

```css
.input {
  width: 100%;
  background: var(--surface);
  border: var(--bd-w) solid var(--ink);
  border-radius: var(--radius);
  padding: 13px 15px;
  font: 600 16px var(--font);
}
.input:focus { outline: none; border-color: var(--ink); box-shadow: var(--e-press); }
```

Ширину рамки при фокусе **не уменьшать**: обводка должна крепнуть, а не слабеть.

### Сегментированный переключатель

```css
.seg { display: inline-flex; border: var(--bd-w) solid var(--ink); border-radius: var(--radius); overflow: hidden; }
.seg button { border: 0; background: transparent; padding: 7px 12px; font: 700 12px var(--font); }
.seg button[aria-pressed='true'] { background: var(--ink); color: #fff; }
```

`overflow: hidden` здесь обязателен, чтобы активная заливка не выходила за
скругление, — но помните о нём в разделе про пальцевые цели.

### Боковое меню (десктоп)

Карточка на всю высоту, 196px шириной, без скругления. Логотип сверху в блоке
с линией `2px` под ним. Пункты — строки по 62px, иконка слева, подпись справа.
Активный пункт — **терракотовая полоса во всю ширину карточки**, текст на ней
чернильный (7.1:1), а не белый (3.9:1). Внизу под линией — язык и настройки.

### Состояния ответа

```css
.option           { background: var(--surface); border: var(--bd-w) solid var(--ink); }
.option.correct   { background: var(--lime);    color: var(--ink); }
.option.wrong     { background: var(--bad);     color: #fff; }
```

Кружок с буквой внутри цветного варианта — полупрозрачные чернила
`rgba(17,17,16,.16)`, не белая вуаль: белая давала 1.26:1.

## 7. Движение

| Событие | Что происходит |
|---|---|
| Наведение | `translate(-2px, -2px)` + тень 6 → 9 |
| Нажатие | `translate(1px, 1px)` + тень 6 → 3 |
| Появление | сдвиг снизу 8px + прозрачность, 0.55s, каскадом по 40–50ms |

Длительность 0.12s на состояния, 0.55s на появление. Больше — стиль становится
вязким.

## 8. Запреты — каждый оплачен ошибкой

**Лайм не даёт тона.** Контраст с бумагой 1.13, с белой карточкой 1.26 при
разнице светлоты всего 4.6 — при этом он самый насыщенный в палитре. Он
одновременно кричит и не имеет веса. Затемнение не спасает: даже `#9db300` даёт
2.11. Вывод: лайм годится **малыми пятнами** (квадрат иконки, метка), а на
больших плоскостях его держит только рамка. Хотите лайм на всю карточку —
готовьтесь, что она будет выглядеть плоской.

**Лайм и светлый амбер нельзя делать обводкой иконки.** Как штрих на светлом
они дают 1.26 и 2.13, а порог для нетекстовых элементов — 3:1. Иконка
получается невидимой. Тёмные варианты тех же семейств проходят:
`#6f7d00` (4.56) и `#b06a12` (3.72).

**Белый текст на лайме — 1.26:1.** На лайме текст только чернильный. Это
касается и кнопки успеха, и метки «ответ», и верного варианта.

**Не давайте двум ролям похожий цвет.** Проверка простая: ΔE2000 между любыми
двумя смысловыми цветами должен быть больше 10, а лучше больше 20. У нас
однажды сошлись цифра достижения и цвет ошибки — ΔE 3.9, то есть один цвет на
глаз, и достижение выглядело как ошибка. Для набора из нескольких категорий
держите минимум **ΔE ≥ 21** — тогда их не спутать.

**Вторичная поверхность должна отличаться от фона.** `#f0eee9` на фоне
`#f4f2ee` — это ΔE 1.0, то есть токен не работал совсем: наведение не давало
отклика, блок ответа не читался как поверхность. Держите ΔE ≥ 4.

**Ловушка «Уменьшения движения».** Если элемент начинается с `opacity: 0` и до
единицы его доводит анимация, то в блоке `prefers-reduced-motion: reduce`
анимацию снимать нельзя, не вернув прозрачность:

```css
.stagger > * { opacity: 0; animation: fadeUp .55s forwards; }

@media (prefers-reduced-motion: reduce) {
  .stagger > * { animation: none; opacity: 1; }  /* без второго свойства — пустой экран */
}
```

Мы на этом потеряли два экрана целиком у всех, у кого настройка включена.

**Пальцевые цели — 44×44.** Пилюли этого стиля выходят 28–34px высотой, по ним
неудобно попадать. Расширять невидимым слоем можно только там, где родитель не
обрезает содержимое: у сегментированного переключателя стоит `overflow: hidden`,
и слой там срежется — придётся растить настоящую высоту.

**Плавающие элементы перекрывают контент.** Если что-то висит `position: fixed`
сверху, отступ контента считайте по факту: верхняя координата + высота +
просвет. И добавьте `env(safe-area-inset-top)` — иначе при установке на
домашний экран элемент уедет под вырез.

**Высота экрана — `100dvh`, не `100vh`.** `100vh` в iOS Safari включает полосу
под адресной строкой: колонка получается выше экрана и нижняя панель уходит за
сгиб.

## 9. Чек-лист перед сдачей

- [ ] Все рамки 2px и цвета чернил, без исключений
- [ ] Все тени чернильные и без размытия
- [ ] Радиус 2px везде, кроме настоящих кругов
- [ ] Один гротеск, различие только в весе
- [ ] Поля ввода 16px
- [ ] На лайме нет белого текста
- [ ] Ни одна иконка не нарисована лаймом или светлым амбером
- [ ] Между смысловыми цветами ΔE2000 > 20
- [ ] Вторичная поверхность отличается от фона (ΔE ≥ 4)
- [ ] Каждое `opacity: 0` + анимация имеет возврат в блоке reduced-motion
- [ ] Цели нажатия ≥ 44×44 на телефоне
- [ ] `100dvh`, `env(safe-area-inset-*)` у фиксированных элементов
- [ ] Контраст: текст ≥ 4.5:1, крупный ≥ 3:1, иконки и рамки ≥ 3:1

## 10. Что стоит знать про перенос

Стиль устроен так, что **рамка и тень несут почти всю работу**. Отсюда следствия
для другого проекта:

- Он плохо переносится на **тёмную схему**: чернильная тень на тёмном фоне
  исчезает, а вся физика уходит вместе с ней. Тёмный вариант — это отдельная
  система, а не инверсия этой.
- Он плохо переносится на **плотные интерфейсы** — таблицы, длинные списки,
  дашборды. 2px рамка и тень 6px требуют воздуха; на двадцати строках подряд
  это превращается в решётку. Для таких мест оставляйте рамку, но убирайте тень.
- Он **не любит фотографий**. Фото рядом с плоскими заливками выглядит
  чужеродно. Если фото нужно — обесцветьте его и дайте ту же 2px рамку.
- Ему нужен **минимум один цветной акцент на экран, но не больше двух**. Три
  цветных пятна в одном поле зрения разваливают иерархию.
